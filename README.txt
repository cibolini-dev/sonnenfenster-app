SONNENFENSTER – APP-PROTOTYP

Schnelltest:
1. Ordner entpacken.
2. index.html öffnen. Die App funktioniert bereits als klickbarer Prototyp.
3. Für die echte PWA-Installation muss der Ordner später über HTTPS oder einen lokalen Webserver bereitgestellt werden.

Enthalten:
- Startseite mit Sonnenfenster-Plätzen
- 14 Regionen
- schematische Regionenkarte
- Filter (Hund / Restaurant / Wetterjoker)
- Favoriten, lokal gespeichert
- Donnerstagabend-Entscheid
- Detailseiten mit Tour des Tages
- Links zu Google Maps
- Links zu den vorhandenen Sonnenfenster-PDFs
- PWA-Manifest + Service Worker als Grundlage für Installation/Offline

Prototyp-Daten:
- Luz-Saint-Sauveur / Camping Le Bastan
- Cauterets / Camping La Prairie
- Torla-Ordesa / Camping Río Ara
